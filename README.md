## Featured project

### [DayFlip](https://github.com/Moeyo777/DayFlip) · [Live demo](https://moeyo777.github.io/DayFlip/)

A browser start page modeled on the Korean tear-off daily calendar (일력).
Each day, yesterday's sheet tears away and today's appears.

<a href="https://moeyo777.github.io/DayFlip/">
  <img src="https://raw.githubusercontent.com/Moeyo777/DayFlip/main/screenshot.jpg" alt="DayFlip screenshot" width="720">
</a>

| | |
|---|---|
| **Calendar** | Lunar dates, plus public holidays for Korea or the United States, calculated on the device |
| **Daily tools** | Google search, up to 9 favorite sites with number-key shortcuts, and a memo that clears at midnight |
| **Personal dates** | Yearly anniversaries (solar or lunar) and one-time D-day countdowns |
| **Weather** | Current conditions for a chosen city via Open-Meteo, with no API key and no location permission |
| **Languages** | Korean and English, chosen separately from the calendar region |
| **Engineering** | One HTML file, no build step, a strict Content Security Policy, and all personal data kept in the browser |

## How I work

- **Small and complete.** Ship one focused tool and finish it properly before starting the next.
- **Accessible by default.** Keyboard shortcuts, visible focus, screen-reader text and reduced-motion support.
- **Private by default.** No accounts, no tracking, and no personal data leaving the browser.
- **Documented.** Every project has a clear README, a design system document and versioned releases.
